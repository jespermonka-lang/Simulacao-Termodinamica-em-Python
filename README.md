# Simulação Computacional de Gases – Termodinâmica

## Sobre o projeto

Projeto acadêmico desenvolvido durante a graduação em Engenharia de Computação no CEFET-RJ, na disciplina de Termodinâmica.

O trabalho consiste no desenvolvimento de simulações computacionais em Python para estudar o comportamento de gases ideais e reais em sistemas bidimensionais, aplicando conceitos de física, matemática e programação.

## Funcionalidades

- Simulação do movimento de partículas em duas dimensões.
- Modelagem de gases ideais e reais.
- Simulação de um recipiente com pistão móvel.
- Modelagem das interações de atração e repulsão entre partículas.
- Aplicação da equação de Langevin em sua forma simplificada.
- Aplicação do potencial de Lennard-Jones.
- Detecção e tratamento de colisões.
- Integração numérica pelo método de Euler-Cromer.
- Visualização dinâmica do movimento das partículas.
- Geração de gráficos de forças e histogramas de velocidades.
- Análise do comportamento térmico e mecânico do sistema.

## Tecnologias utilizadas

- Python.
- NumPy.
- Matplotlib.
- Programação orientada a objetos.

## Conceitos abordados
